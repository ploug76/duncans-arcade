2. Put each game on the Home Screen as its own tile

Phones only let a game be added from that game's own page, one at a time. A web page can't add icons for you. Tap Open game, then follow the steps for your phone, then come back here for the next one.
iPhone / iPad (use Safari):
  1. Tap Open game below. The game opens in Safari.
  2. Tap the Share button (the square with an arrow; on iPhone it's at the bottom of the screen or behind the ••• button).
  3. Scroll down and tap Add to Home Screen . Make sure Open as Web App is on if you see it.
  4. Tap Add. The game's own picture shows up as a tile on the Home Screen.
If you're inside the installed arcade and there's no Share button, tap Copy link, paste it into Safari, then do the steps above.
Android (use Chrome):
  1. Tap Open game below. The game opens in Chrome.
  2. If an Install bar or icon pops up, tap it, then tap Install.
  3. If not, tap the menu ⋮ at the top right, then Add to Home screen (or Install app), then Install or Add.
  4. The game's tile appears on the Home Screen (you may need to drag it from the app list).

Volume

Off by default and kept quiet. Phones only allow sound after the first tap, so it plays on Duncan's first tap. Each game has its own mute button.

Important: this lock only protects the arcade page itself (hiding, reordering, sound, install help). A web page can't stop a phone's own "Remove App"/"Delete" on Home Screen icons, or block the phone's Settings. To stop that, use the phone's built-in parental controls below.

iPhone / iPad

Stop apps from being deleted (Screen Time):
  1. Settings → Screen Time (set a Screen Time passcode Duncan doesn't know).
  2. Content & Privacy Restrictions → turn it on.
  3. iTunes & App Store Purchases → Deleting Apps → Don't Allow.
On a child's device managed with Family Sharing on iOS 27, the same switch is under Apps & Websites → Restrictions (set Deleting Apps to Blocked). Apple doesn't say whether this also covers web-app icons added from Safari, so test it by pressing and holding an icon. Guided Access below is the sure lock.
Lock the phone to one app (Guided Access):
  1. Settings → Accessibility → Guided Access → turn on, and set a passcode in Passcode Settings.
  2. Open Duncan's Arcade (or a game), then triple-click the side button (Home button on older phones) → Start.
  3. Triple-click and enter the passcode to end it.

Android

Lock the phone to one app (App pinning):
  1. Settings → Security (or Security & location) → Advanced → App pinning → turn on. (The menu name can vary by phone maker.)
  2. Open the arcade, go to Overview (swipe up and hold), tap the app's icon at the top → Pin.
  3. Unpinning asks for the phone's PIN, pattern or password.
Google Family Link: use the Family Link app to block apps, set screen time limits and require approval for Play downloads. Google's help pages don't promise that it stops Home Screen web icons from being removed, so app pinning is the sure lock.
